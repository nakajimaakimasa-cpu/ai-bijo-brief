# 規約・法律チェックリスト（2026-11-07 時点）

この導線（SNS → note → LINE → Web会議の個別相談 → 有料の伴走）は、**いま国や消費者センターがいちばん注意している形**と同じです。
国民生活センターは2026年9月16日、AI講座などの「ビジネス講座」の相談が増えていると公表しました。挙がった例は「AIで副業」の広告 → 1万円の商材 → メッセージアプリ → Web会議 → 約80万円・36回払い、というものです[64]。
消費者庁も2025年6月、SNSの副業広告からLINE、電話の勧誘で250万円のプランを契約させた業者を公表しています[66]。

中身がまっとうでも、**見え方が同じだと疑われる**。だから、このアカウントは「透明さ」で違いを作ります。
下の **Do／Don't** を、投稿・note・LINE・相談のすべてに当てはめてください。

> [n] は末尾の出典です。法律の判断が必要な場面（契約書の文面、伴走の中身が特定継続的役務提供に当たるか、など）は、専門家に確認してください。

## 0. まず、これだけ

| ✅ やる | ❌ やらない |
|---|---|
| 個別相談の**予約ページ・LINEの案内・相談の冒頭**で、事業者名・担当者名・有料の案内をすること・商品の種類を言う | 「無料相談」「交流会」と言って、勧誘の目的を伏せる |
| 伴走の申し込みは**法定の書面**で（承諾があれば電子でも可）。受け取ってから**8日間のクーリングオフ**を案内する | 「今日だけ」「今決めれば特典」で即決を迫る。断られた後にまた勧める |
| 総額・期間・途中でやめるときの条件を、契約の前に見せる | 借入・カードの分割・個別クレジットをすすめる |
| 実績・数字は実数か出典つき。母数や「できなかった人」も書く | 「必ず稼げる」「すぐ元が取れる」「誰でも」「◯◯するだけ」 |
| 感想は本人の許可を取った本物だけ | 作った感想、サクラ、サブアカウントの口コミ |
| 先着の部数・値上げは言ったとおりに実行する | 守らない「先着◯名」、架空の「通常価格」 |
| 関係のある会社（Addness など）を勧めるときは関係を書く | 関係を伏せた紹介（ステマ） |
| お店へは、電話か訪問で「送っていいか」を聞いてから送る | Googleマップから自動で集めたリストに、メールを一斉に送る |

## 1. 特定商取引法

### 個別相談（Web会議）は「電話勧誘販売」になる

- 事業者がWeb会議のURLを送って話すのは「電話をかけ」に当たり、映像つきのネット通話も「電話」に含まれる[51]
- 消費者庁のQ&Aの例：情報商材を買ったあとSNSでやり取りし、Web会議で別の商材を勧められた → 電話勧誘販売としてクーリングオフが使えると考えられる。**「相談」の目的で予約しただけでも、除外にはならない**[51]
- 2023年6月1日から、ウェブ広告などで勧誘の目的を言わずに電話をかけさせるやり方も対象に加わった[52][53]
- LINE通話を名指しした記述はないが、同じネット通話として扱われると考えておく

**やること**
- 予約ページ・LINE配信・相談の冒頭で：事業者名、担当者名、**有料の商品を案内すること**、商品の種類[51][54]
- 申し込みは法定の書面（承諾があれば電子でも可）。受け取ってから8日間のクーリングオフ[54][55]
- 総額・期間・中途解約の条件を契約前に[64]

### ほかに当たる可能性があるもの

- **業務提供誘引販売**：「仕事を紹介する」「案件を回す」と約束して講座を売ると、こちらに当たる（クーリングオフ20日）。約束しない[57]
- **特定継続的役務提供**：2か月を超えて5万円を超える講座は、「パソコン教室」に当たるか確認する（AI講座が当たるかは未確認）[58]
- **通信販売**（noteで売る分）：特商法の表記が要る（下の note の項）[56]

### お店（個人事業主）への営業

- お店の仕事のための契約は、原則として特商法の対象外。ただし、主に家庭用・個人用の場合や、規模が小さく実質的に消費者と同じと見られる場合は当てはまることがある[37]
- 個人のお店には、書面と解約の条件を渡す。長期リースや即決を求めない。断られたら再訪・再電話はしない

## 2. 景品表示法

- **ステマ規制**（2023年10月〜）：広告主が関わった投稿は、広告だと分かるように。依頼して書いてもらった投稿も広告[59]
- **直罰**（2024年10月〜）：優良誤認・有利誤認に100万円以下の罰金[60]
- **不実証広告**：効果をうたう表示は、15日以内に合理的な根拠を出せなければ不当表示とみなされる[61][62]
- 体験談に「個人の感想です」と添えても、受け止め方はほとんど変わらない[63]
- 実績を出すときは、母数・達成した人の割合・達成しなかった人の割合を書き、根拠の資料を残す[61][63]

## 3. note

| 項目 | 内容 |
|---|---|
| 禁止 | 「必ずもうかる」など著しい誤解を招く表現、マルチ商法など不利益をもたらす情報商材、その宣伝への利用やそうしたサイトへのリンク[22][23] |
| 利用停止の理由 | **売上・利益を公開して購入を煽る**こと（確定・未確定を問わず）[22]。売上のスクショで告知しない |
| 景表法の頁（2026/5新設） | 根拠のない「必ず効果」「絶対に失敗しない」、比較のない「No.1」、ありふれた手法の「独自メソッド」、守らない「先着10名」、架空の二重価格、ステマ[24] |
| LINEへの誘導 | 一律に禁止する決まりは見つからない。note自身が有料の「LINE友だち追加」オプションを出している[26][27] |
| 値段と手数料 | 100〜50,000円。docomo・au のキャリア決済は1回1万円まで。手数料は決済5%（カード）〜15%（キャリア）＋利用料10%、振込1回270円[30][31] |
| 返金 | 有料記事は初期設定で「返金可」（購入から24時間以内に申請、noteが審査）。不可にもできる。マガジンは返金不可[32][34] |
| 特典 | 総付景品の上限は、取引価額1,000円以上なら価額の20%。会員限定記事は対価に含まれるので対象外[38]。**特典は「付録（購入した人が読めるデータ）」として本文の一部に位置づける**。購入者だけの無料の個別相談は景品になり得るので、個別相談は誰でも受けられる形にしておく |
| 表記 | 営利目的で反復して売るなら「販売業者」として住所・氏名・電話番号。請求があれば遅滞なく開示する旨を書けば省略できる[39]。初めて有料記事を出すときは本人情報の登録が必要（2024/4〜）[41] |
| AI学習 | 有料記事も「AI学習対価還元プログラム」の対象（初期設定でオン、オプトアウト可）[42] |

## 4. Threads（Meta）

| 項目 | 内容 |
|---|---|
| リンク | Metaは「意図的に下げてはいない」と説明（2024/11・2025/6）。プロフのリンクは最大5本、クリック数はインサイトで見られる[1][2][3] |
| トピックタグ | 1投稿1つまで。プロフィールには最大10[1][4] |
| 予約・下書き | 予約は最大75日先まで、返信は予約できない（報道）。下書きは最大100件[7][8] |
| 頻度 | 公式は「投稿が多いほど1投稿あたりの閲覧が多い」として、少なくとも週2〜5回をすすめる。閲覧のおよそ半分は返信から[9][10] |
| 配信を絞られるもの | クリックベイト、エンゲージメントベイト、懸賞、オリジナルでない投稿[9] |
| お金の話 | 特定の言葉を下げるという公式の記述は見つからない（「収ｴｷ化」のような伏せ字は言い伝え）。ただし「不明確・最小限の労力で非現実的な金銭的報酬」をうたう機会の提供は、詐欺として削除の対象[12][13] |
| 確認できる所 | 「アカウントステータス」で、おすすめの対象外になっていないかを見て、異議申し立てができる[17] |
| PR・AI | 有償の案件には「Paid partnership」ラベル。写実的なAI動画・音声は申告が必須[18][19] |

## 5. LINE（公式アカウント・オープンチャット）

**公式アカウントのガイドライン（2026/9/30更新、未認証にも適用）で掲載できない例**[45][46]
- 情報商材：「儲かる／儲ける」などをうたって集め、メルマガ・動画販売・セミナーなどへ誘導するもの
- 能力開発商材：「◯◯するだけ」など、簡単に始められるとうたって誘導するもの
- 当てはまると、アカウントの停止や契約の解除もあり得る。**LINEの文面では「稼げる」「儲かる」「◯◯するだけ」を使わない**

**料金（税別）**[47][48][49]

| プラン | 月額 | 通数 |
|---|---|---|
| コミュニケーション | 0円 | 200通（追加不可） |
| ライト | 5,000円 | 5,000通（追加不可） |
| スタンダード | 15,000円 | 30,000通（追加は2026/10から月20万通まで1通3円） |

ステップ配信などは受け取る人数分数えられる。合言葉などへの応答メッセージは数えられない。

**エルメ（税込）**[50]：フリー0円（エルメ側の配信は月1,000通、ステップ配信可、フォーム3、リッチメニュー2、面談予約1、広告表示あり）／スタンダード10,780円／プロ33,000円。LINE公式アカウント側の通数の上限は別にかかる。

**オープンチャットのガイドライン（2024/3/11更新）で禁止**[43]
- LINE IDやほかのSNSの連絡先（QRを含む）、電話番号、住所の投稿
- ほかのルームの招待URLを乱発しての勧誘
- ネットワークビジネスの勧誘など、経済的な危害のリスクが高い行為
- 口座・QR・受け取りURLを示して送金させること
- LINE利用規約も「営業、宣伝、広告、勧誘、その他営利を目的とする行為（当社の認めたものを除く）」を禁止[44]
- → **オープンチャットは交流の場にとどめ、販売の勧誘はしない。公式LINEやnoteのURLも貼らない**

## 6. お店への営業（特定電子メール法・Googleマップ・個人情報）

**特定電子メール法**（営業メールもSMSも対象）[35]
- 原則は事前の同意が要る。例外：取引関係にある相手／名刺などでアドレスを知らせてきた相手／**アドレスを自分で公表している団体・営業している個人**（「広告メールお断り」などと書いてあれば送れない）
- 必ず書く：送り主の名前、受け取りを断れることとその連絡先、住所、問い合わせ先
- 断られた後の送信は禁止。同意をもらって送るときは、同意の記録を残す
- 問い合わせフォームやSNSのDMの扱いは、はっきりした公的見解がない → 同じルールで扱う[36]
- いちばん安全なのは、**電話で「見本のURLを送ってもよいですか」と同意をもらい、記録してから送る**こと

**Googleマップ**[39][40][41]
- 自動での抜き出し（スクレイピング）、事業者名・住所・口コミのコピー保存、一括ダウンロード、営業リストづくりは規約で禁止
- APIを使う場合も、保存してよいのは place_id などのIDだけ
- 口コミの文章や写真を、見本サイトに無断で載せない

**個人情報**[38]
- 個人事業主の名前や電話番号が入った営業リストは「個人情報データベース等」に当たり得る。利用目的を通知か公表する → 自分のサイトにプライバシーポリシーを置く
- LINEのアンケートで集める情報も同じ

**クラウドソーシングの直接取引**[42c][43c][44c]
- クラウドワークス：連絡は原則サービス内。会員とのサービス外の契約とその勧誘、報酬の直接のやり取りは禁止。違反の違約金は「システム利用料相当額か100万円の大きい方」
- ランサーズ：利用中と利用終了後1年間は直接取引を禁止
- ココナラ：外での直接取引を持ちかけること、応じることを禁止

**インボイス**[34c]
- 免税事業者からの仕入れの控除の割合は、2026年10月から70%（2028年10月50%、2030年10月30%、2031年10月0%）。法人・課税事業者のお客さんが多いなら登録を考える

**自分が外注する側になったとき**
- フリーランス法（2024年11月施行）：取引条件を書面などで明示、受け取ってから60日以内に支払う[45c]

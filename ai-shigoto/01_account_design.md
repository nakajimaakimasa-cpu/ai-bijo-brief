## 0. 結論（先にこれだけ）

| 項目 | 決めたこと |
|---|---|
| **コンセプト** | **「AIに作業、自分は営業。」** AIで"作れる"を"仕事"にする順番を、盛らずに、手順と出典で出す |
| **誰に** | AIは触れるのに仕事にならない人（会社員の副業・フリーランスの卵・個人事業主） |
| **取り方（採用ルート）** | ①やる仕事を1つ・小さな商品に → ②知り合いに聞いて最初の事例 → ③クラウドソーシングで評価を貯める（期限2か月）→ ④AIエージェントで探す・見本・提案を速く → ⑤Googleマップで地域のお店に見本を持って会いに行く → ⑥1回きりを毎月の仕事に |
| **なぜこのルートか** | 海外の8つの型を比べると、再現しやすいのは「知り合い」(5点)・「Googleマップ×見本」(4点)・「定額の小商品」(4点)。日本でも仕事の経路は人脈が68.3%で最多、クラウドソーシングが「いちばん稼げた経路」は5.8%（§2） |
| **導線** | Threads（毎日3本）→ 無料note → 公式LINE（スターターキット）／有料note（合言葉で特典）→ 7日間の配信 → 個別相談（30分）→ 合う人にだけ伴走 |
| **最初の3週間** | 1週目：信用をつくる（自己紹介・実録・型）／2週目：海外比較シリーズ／3週目：有料note発売 |
| **特典で書くこと** | AI社員（Claude Code）・Obsidianで会社の脳・Addness連携。noteの特典章でしっかり書き、Threadsでは「チラ見せ」で興味を作る |

**決めてほしいこと（これが決まらないと3週目に進めない）**

| # | 決めること | 私の提案 |
|---|---|---|
| A | 名前の出し方・顔出し | 「あきまさ」＋顔写真。このジャンルは「怪しい」と思われやすく、顔なしは相談の前に疑われる理由になる |
| B | 伴走（個別相談の先）の中身と価格帯 | 個別相談の**前に**LINEで価格帯を伝える。今売っている講座を差し込むか、自分の伴走を作るかを決める |
| C | 有料noteの値段 | 先着30部 2,980円 → 31部目から 4,980円（参考アカウントと同じ「限定部数→値上げ」） |
| D | Addnessとの関係の書き方 | 業務委託などの関係があるなら、特典章とその告知の投稿に1行で明記する（ステマ規制） |
| E | 屋号と、特定商取引法の表記に出す情報 | note（販売者情報）と個別相談の案内に、事業者名・責任者・連絡先を出す。住所・電話は「請求があれば遅滞なく開示」でも可 |

> **この導線は、いま注意されている形と同じ**です。国民生活センターは2026年9月に、「AIで副業」の広告 → 安い商材 → メッセージアプリ → Web会議 → 約80万円の分割契約、という相談が増えていると公表しました。
> 違いを作るのは中身ではなく**透明さ**です：顔を出す／価格帯を先に言う／有料の案内があることを先に言う／借入をすすめない／書面とクーリングオフ。くわしくは `06_rules.md`。

## 2. 海外のAIのプロ比較 → 日本で再現しやすいルート

2026-11-07 に調べた。**海外の成果は、ほぼすべて本人か自社の発表**で、うまくいった人の話だという前提で読む。
再現しやすさは「日本の初心者〜中級者がやった場合」の5点満点（私の評価）。

| 型 | 代表 | やり方 | 成果の根拠 | 再現しやすさ |
|---|---|---|---|---|
| A AI代理店 | Liam Ottley（Morningside AI） | YouTube・無料コミュニティで集める → 業種ごとのデモ → 会社に仕組みを作り月額で保守 | 「受講7,250社超・獲得クライアント1,000件超」（自社発表）[1] | **2**：高い仕組みを会社に売るのは、日本では事例と信用が先。受講数に比べて獲得数が少ない |
| B 地元→仲介サイト→型 | Nick Saraev | 2019年に地元店を1日50〜100件訪問 → Googleマップ掲載代行200ドル → 仲介サイトで小さな自動化300〜500ドル → 型にして大型へ[2][3] | 地元向けで約1年に15万ドル超（本人談）[3] | **原型2／順番だけなら4**：英語の大量メールは日本の法律に合わない。順番は再現できる |
| C 海外の仲介サイト | Upwork（公式データ） | AI動画・AI統合などに絞って提案 → 小案件 → 評価 → 単価アップ | AIスキルを持つ人の取引額は前年比+55%、サイト全体は−10.1%（2026年7〜9月期決算）[4] | **2**：英語・時差。「何が伸びているか」の地図として使う |
| D Googleマップ×見本 | Lovable 公式動画・X上の実践者 | 業種×地域で25〜30件 → 上位5〜8件に見本 → 短い文面＋動画 → 追いかけは2回 → 15分の打ち合わせ。400〜1,500ドル＋月99〜199ドル[5][6] | 「9日で初受注」「最初は40〜70件に連絡して1件」（本人談）。公式動画でも電話はすぐ切られ、メールに切り替えている | **4**：日本の小さなお店に直結。集め方と連絡のしかたを日本の規約・法律に合わせる |
| E AIの電話受付 | Vendasta（7,000社調査） | 他社の仕組みを自社名で設定代行＋月額 | 「AI受付」と書くと関心4%、成果で書くと81%が「最も価値がある」[7] | **2**：国内には月2,980円〜の既製品（IVRy）がある。単体で売るより、既存のお客さんへの追加向き |
| F 知り合いに聞く | Alex Hormozi | 知人に1対1で「困っている人いない？」→ 最初の数件は無料か実費 → 感想と紹介[8] | 枠組みのみ（数字なし） | **5**：日本でも仕事の経路は「人脈」が68.3%で最多（下の表） |
| G 発信で集める | Nate Herk ほか | 事例・デモを出し続ける → テンプレを配る → 問い合わせ | 問い合わせ最大8件/日。本人の評価は「初心者の容易度1/10（実績が前提）」[9] | **3**：信用を広げる道具。最初の1件の手段としては遅い |
| H 定額の小商品 | Designjoy | 1商品・定額・範囲固定 | 月4,995ドル・年130万ドル・顧客約20（2023年、本人談）[10] | **4**：日本の「保守・Googleマップ整備の月額」と同じ形 |

**読み取れること**
1. 派手なものほど点が低く、地味で近いものほど点が高い
2. 共通する最初の一手は「地元の、具体的で、説明しやすい小さな商品」（Nick の200ドルのマップ掲載代行）
3. 「AI」ではなく「結果」を売る（4% と 81% の差）
4. 目に見える「プロ」の収入は、教育事業の比重が大きい

### 採用するルート

あなたの最初の案（AIエージェントで幅を広げる → クラウドソーシング × Googleマップのオフライン営業）を土台に、比べて分かった2つを足した。**最初に「知り合い」**、**最後に「毎月の仕事」**。

| 段 | やること | 元の型 | 期間の目安（提案） |
|---|---|---|---|
| ① | やる仕事を1つに決め、小さな商品にする（例：Googleマップの情報整備＋1ページのサイト） | H | 1日 |
| ② | 知り合い100〜200人に「ホームページやマップで困っているお店、知らない？」と聞く。最初の3〜5件は無料か実費で引き受け、事例・感想・紹介をもらう | F | 0〜2週 |
| ③ | クラウドソーシングで評価を貯める。**期限は2か月**。汎用のAIライティングは避け、「AIで作ったものの仕上げ」「AIの導入・自動化」に絞る | 国内版C | 〜2か月 |
| ④ | AIエージェントで、探す・調べる・見本・提案書を速くする（**送るのは自分**） | B・D | ずっと |
| ⑤ | 1地域×1業種で週20〜30件を手でリスト → 見本 → 電話か訪問で「送っていいか」を聞く → URL → 15分 → 見積もり | D | 1〜4か月 |
| ⑥ | 保守＋Googleマップ整備を月額に。上の段で、既製のAI電話・チャットの設定代行 | H（＋E） | 3か月〜 |
| 並走 | Threadsで毎週の数字（連絡→返事→相談→受注→単価）を出す。「再現できるかの検証」そのものを発信にする | G | ずっと |

**日本向けに変える所**
- **AIの使いどころ**：送信の自動化ではなく、1件ごとの調査・見本・提案書の時短に使う（規約と法律の制約は「集める」「送る」の側にある）
- **言い方**：「AIで安く」ではなく「電話の取りこぼし」「マップから来るお客さん」で話す。AIを使うことは見積もりと契約書に書く
- **狙うお店**：「HPがない店」だけだと数が少ないかもしれない（古い参考値：東京の10人以下の事業所でもHP開設率84.1%・2011年度[19]）。「古い・スマホで見づらい・予約の入口がない店」も入れる
- **信用**：屋号・所在地・電話番号・顔写真・事例のページ、紙の提案書（QRで見本へ）、商工会・税理士・信用金庫からの紹介
- **請求**：インボイス制度で、免税事業者からの仕入れの控除の割合が2026年10月から70%に下がった[20]。法人や課税事業者のお客さんが多いなら、登録を考える

## 3. 誰に（ターゲット）

これまでの個別相談で多かった声から、3つのタイプに分ける（個人が分かる情報は入れていない）。

| タイプ | どんな人 | よく出る言葉 | 最初に渡すもの |
|---|---|---|---|
| **A 未経験** | 会社員・パート。AIは少し触った。副業か、体を使わない働き方を探している | 「何を質問していいか分からない」「スクールに入ったけどサポートがなかった」 | やる仕事を1つに決める質問（AIに聞いてもらう） |
| **B 応募中** | クラウドソーシングで応募しているが通らない | 「AIで書いた提案文がどれも同じになる」 | 見本つきの提案文の型 |
| **C 事業者** | 整体・教室・カウンセラーなど、自分の仕事にAIを入れたい | 「考えることと作業が混ざっている」「Codeという名前でエンジニア向けだと思っていた」 | AI社員の社則5行 |

**相談の前に必ず出てくる不安**：「LINE→Zoom→いきなり高額」「顔を出していない」「費用が分からない」。
→ だから、顔を出す・価格帯を先に言う・断ってよいと言う、を最初から設計に入れている（§7）。

## 4. コンセプトと言葉

**一言**：AIに作業、自分は営業。
**約束**：盛らない／手順と出典を出す／できないことは、できないと言う。

| 使う言葉 | 使わない言葉 |
|---|---|
| 仕事を取る・案件・最初の1件・順番・見本・提案 | 稼げる・不労所得・誰でも・絶対・必ず・爆速・放置で |
| 作業はAI、判断と営業は人 | AIが全部やってくれる |
| 実録（数字は実数）・出典 | 「月◯万円」を見出しにする（実数で証明できるときだけ本文に） |

**ほかの発信との違い**

| | よくある発信 | このアカウント |
|---|---|---|
| AIの使い方系 | ツールの紹介・プロンプト集 | 「それで、どう仕事にするか」まで出す |
| AIで稼ぐ系 | 金額の大きさ・楽さで引く | 順番・手順・失敗・出典で引く |
| 営業系 | 気合い・トーク術 | AIで準備を軽くして、売り込まない営業 |

## 6. 投稿の設計

### 1日3本の時間割

| 時間 | 型 | 長さ | ねらい |
|---|---|---|---|
| 07:30 | 考え方 | 短い（〜150字） | 「わかる」と思ってもらう。リプが付きやすい |
| 12:30 | 型 | 中（200〜400字） | 保存される。「この人の型は使える」 |
| 20:30 | 実録・戦略・告知 | 長め＋続き | 信用を積む。リンクは続きに置く |

### 5つの型（このあと自分で作り続けるときの型）

| 型 | 1行目の作り方 | 例（1行目） |
|---|---|---|
| 考え方 | 言い切る／ひっくり返す | 「AIは、勝手には賢くなりません。」 |
| 型 | 「◯◯の型（保存用）」 | 「クラウドソーシングで通る提案文の型（保存用）」 |
| 実録 | 「僕が◯◯したときの話」＋数字 | 「受講生だった僕が、最初の1件を取るまでの話。」 |
| 戦略 | 比べる／順番を出す | 「海外のAIのプロの取り方を比べたら、再現しやすいのは2つだけだった」 |
| 告知 | 何を・いつ・いくら・誰向け | 「17日目の20時に、有料noteを出します。」 |

**割合**：告知は7本に1本まで（発売週は1日1本まで）。残りは考え方・型・実録・戦略を回す。

### 書き方のルール

- 1投稿1メッセージ。1行目で言い切る
- 1行は20字前後で改行。箇条書きは①②③か「・」
- 数字は**実数か出典つき**だけ。分からない数字は書かない
- リンクは本文に入れず、**続き（スレッドの2投稿目）**に置く（Metaは「リンクを意図的に下げてはいない」と説明しているが、リンクだけの投稿はいいね・返信が付きにくい。本文は反応をもらう役、続きはリンクの役に分ける）
- タグは投稿画面の「#」から1つだけ（1投稿1つが上限。本文に #〇〇 と書いてもタグにならない）
- 予約投稿を使う日は、続き（返信）は予約できないので、出たあとに手で足す
- 「稼ぐ」系の言葉を伏せ字にする必要はない（特定の言葉を下げるという公式の説明は見つからない）。ただし「楽に・すぐ・大きく稼げる」と読める書き方は、Metaの詐欺のルールに触れる
- 実在のお店・会社・お客さんの名前は出さない

### 交流のルール

- 出してから30分は、付いたリプに全部返す（Metaによると、閲覧のおよそ半分は返信から生まれる）
- 同じジャンルの発信者の投稿に、心が動いたときだけ本気でリプする（相互フォロー・インサイト祭りはしない）
- 質問のリプは、次の日の「型」の投稿のネタにする

### 投稿ボードの使い方

- `posts.csv` は、いま使っている「投稿ボード」のスプレッドシートと同じ列（順番・区分・いつ・題・本文・続き・メモ・タグ・完了・完了した日時・画像・鍵）＋「型」
  → そのままシートに貼れば、今のGASのボードでも使える
- `board.html` はスマホで開くだけで使える版（「本文をコピー」「Threadsで開く」「続きをコピー」「投稿した」）
- 【】の所は、事実に合わせて直してから出す

### 22日目からの投稿の足し方（AIへの頼み方）

```

・約束：盛らない／手順と出典を出す／できないことは、できないと言う
・使わない言葉：稼げる・不労所得・誰でも・絶対・必ず
・1日3本：07:30 考え方（150字まで）／12:30 型（200〜400字・保存用）／20:30 実録か戦略（本文400字まで＋続き）
```

## 7. 導線（どこで、何と言って、次に進めるか）

```
Threads（毎日3本・20:30が主役）
  ├─ 固定投稿の続き ───────────▶ 無料note
  ├─ プロフのリンク1本目 ─────────▶ 無料note
  ├─ プロフのリンク2本目 ─────────▶ 公式LINE（スターターキット）
  └─ 発売週の告知の続き ─────────▶ 有料note
無料note の最後 ─────────────────▶ 公式LINE（入口_無料note）／有料note
有料note の特典の章（合言葉）───────▶ 公式LINE（入口_有料note）
公式LINE（7日間の配信）─────5日目──▶ 個別相談（30分・無料）─▶ 合う人にだけ伴走
公式LINE ─────参加コード────────▶ オープンチャット（週の部活・月1の7日間チャレンジ）
```

| 段 | 次に進める一言 |
|---|---|
| Threads → 無料note | 「順番の全体像は、無料noteにまとめています」 |
| 無料note → LINE | 「この記事を手を動かせる形にしたスターターキットを、公式LINEで配っています」 |
| 有料note → LINE | 「特典は、公式LINEに合言葉を送ると受け取れます」 |
| LINE → 個別相談 | 「自分の場合はどうすれば？と思った方へ。有料の案内もしますが、断ってもらって大丈夫です」 |

note の中身は `03_note.md`、LINEと個別相談は `04_line.md`、オープンチャットは `05_openchat.md`。

## 9. 数字（毎週日曜に10分）

| 見る数字 | どこで | 目安（仮） | 動かないときに直す所 |
|---|---|---|---|
| 1投稿あたりの閲覧 | Threads のインサイト | 2週目で1,000 | 1行目・時間・型の割合 |
| フォロワーの増え方 | Threads | 3週間で +300〜1,000 | 固定投稿・プロフ |

## 10. 規約・法律

`06_rules.md` にまとめている（Threads／note／LINE・オープンチャット／特定商取引法／景品表示法／特定電子メール法／Googleマップ）。
特に大事な5つ：
1. **実績・感想は事実だけ**。作った声、盛った数字、売上のスクショで煽る、はしない（noteは売上を見せて購入を煽ることを利用停止の理由にしている）
2. **個別相談は、Web会議でも「電話勧誘販売」に当たる**。予約ページ・LINE・相談の冒頭で、事業者名・担当者名・有料の案内をすること・商品の種類を言う。申し込みは書面（電子でも可）、8日間のクーリングオフ、借入をすすめない
3. **公式LINEで「儲かる」「◯◯するだけ」と言って相談に誘わない**（LINE公式アカウントのガイドラインで掲載できない例。アカウント停止もあり得る）
4. **お店への連絡は、電話か訪問で「送っていいか」を聞いてから**。メールは送り主・住所・連絡先・配信停止の方法を書く。Googleマップから自動で集めない、口コミや写真を見本に載せない
5. **Addnessなど、関係のある会社のサービスを勧めるときは関係を書く**

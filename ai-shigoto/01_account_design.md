## 0. 結論（先にこれだけ）

| 項目 | 決めたこと |
|---|---|
| **コンセプト** | **「AIに作業、自分は営業。」** AIで"作れる"を"仕事"にする順番を、盛らずに、手順と出典で出す |
| **誰に** | AIは触れるのに仕事にならない人（会社員の副業・フリーランスの卵・個人事業主） |
| **取り方（採用ルート）** | ①やる仕事を1つ決める → ②クラウドソーシングで実績1件 → ③AIで案件探しと提案を数で回す → ④Googleマップで「サイトのないお店」に提案 → ⑤1回きりを毎月の仕事に |
| **なぜこのルートか** | 海外でAIを使って仕事を取っている人たちの型を比べると、日本で再現しやすいのはこの順番（§2） |
| **導線** | Threads（毎日3本）→ 無料note → 公式LINE（スターターキット）／有料note（合言葉で特典）→ 7日間の配信 → 個別相談（30分）→ 合う人にだけ伴走 |
| **最初の3週間** | 1週目：信用をつくる（自己紹介・実録・型）／2週目：海外比較シリーズ／3週目：有料note発売 |
| **特典で書くこと** | AI社員（Claude Code）・Obsidianで会社の脳・Addness連携。noteの特典章でしっかり書き、Threadsでは「チラ見せ」で興味を作る |

**決めてほしいこと（これが決まらないと3週目に進めない）**

| # | 決めること | 私の提案 |
|---|---|---|
| A | 名前の出し方・顔出し | 「あきまさ」＋顔写真。このジャンルは「怪しい」と思われやすく、顔なしは相談の前に疑われる理由になる |
| B | 伴走（個別相談の先）の中身と価格帯 | 個別相談の**前に**LINEで価格帯を伝える。今売っている講座を差し込むか、自分の伴走を作るかを決める |
| C | 有料noteの値段 | 先着30部 2,980円 → 31部目から 4,980円（参考アカウントと同じ「限定部数→値上げ」） |
| D | Addnessとの関係の書き方 | 業務委託などの関係があるなら、特典章とその告知の投稿に1行で明記する（ステマ規制） |

## 4. コンセプトと言葉

**一言**：AIに作業、自分は営業。
**約束**：盛らない／手順と出典を出す／できないことは、できないと言う。

| 使う言葉 | 使わない言葉 |
|---|---|
| 仕事を取る・案件・最初の1件・順番・見本・提案 | 稼げる・不労所得・誰でも・絶対・必ず・爆速・放置で |
| 作業はAI、判断と営業は人 | AIが全部やってくれる |
| 実録（数字は実数）・出典 | 「月◯万円」を見出しにする（実数で証明できるときだけ本文に） |

**ほかの発信との違い**

| | よくある発信 | このアカウント |
|---|---|---|
| AIの使い方系 | ツールの紹介・プロンプト集 | 「それで、どう仕事にするか」まで出す |
| AIで稼ぐ系 | 金額の大きさ・楽さで引く | 順番・手順・失敗・出典で引く |
| 営業系 | 気合い・トーク術 | AIで準備を軽くして、売り込まない営業 |

## 6. 投稿の設計

### 1日3本の時間割

| 時間 | 型 | 長さ | ねらい |
|---|---|---|---|
| 07:30 | 考え方 | 短い（〜150字） | 「わかる」と思ってもらう。リプが付きやすい |
| 12:30 | 型 | 中（200〜400字） | 保存される。「この人の型は使える」 |
| 20:30 | 実録・戦略・告知 | 長め＋続き | 信用を積む。リンクは続きに置く |

### 5つの型（このあと自分で作り続けるときの型）

| 型 | 1行目の作り方 | 例（1行目） |
|---|---|---|
| 考え方 | 言い切る／ひっくり返す | 「AIは、勝手には賢くなりません。」 |
| 型 | 「◯◯の型（保存用）」 | 「クラウドソーシングで通る提案文の型（保存用）」 |
| 実録 | 「僕が◯◯したときの話」＋数字 | 「受講生だった僕が、最初の1件を取るまでの話。」 |
| 戦略 | 比べる／順番を出す | 「海外のAIのプロの取り方を比べたら、再現しやすいのは2つだけだった」 |
| 告知 | 何を・いつ・いくら・誰向け | 「17日目の20時に、有料noteを出します。」 |

**割合**：告知は7本に1本まで（発売週は1日1本まで）。残りは考え方・型・実録・戦略を回す。

### 書き方のルール

- 1投稿1メッセージ。1行目で言い切る
- 1行は20字前後で改行。箇条書きは①②③か「・」
- 数字は**実数か出典つき**だけ。分からない数字は書かない
- リンクは本文に入れず、**続き（スレッドの2投稿目）**に置く
- タグは投稿画面の「#」から1つ（本文に #〇〇 と書いてもタグにならない）
- 実在のお店・会社・お客さんの名前は出さない

### 交流のルール

- 出してから30分は、付いたリプに全部返す
- 同じジャンルの発信者の投稿に、心が動いたときだけ本気でリプする（相互フォロー・インサイト祭りはしない）
- 質問のリプは、次の日の「型」の投稿のネタにする

### 投稿ボードの使い方

- `posts.csv` は、いま使っている「投稿ボード」のスプレッドシートと同じ列（順番・区分・いつ・題・本文・続き・メモ・タグ・完了・完了した日時・画像・鍵）＋「型」
  → そのままシートに貼れば、今のGASのボードでも使える
- `board.html` はスマホで開くだけで使える版（「本文をコピー」「Threadsで開く」「続きをコピー」「投稿した」）
- 【】の所は、事実に合わせて直してから出す

### 22日目からの投稿の足し方（AIへの頼み方）

```
あなたは Threads「あきまさ｜AIに作業、自分は営業」の投稿を書く係です。
・約束：盛らない／手順と出典を出す／できないことは、できないと言う
・使わない言葉：稼げる・不労所得・誰でも・絶対・必ず
・1日3本：07:30 考え方（150字まで）／12:30 型（200〜400字・保存用）／20:30 実録か戦略（本文400字まで＋続き）
・リンクは本文に入れず「続き」に置く。1投稿500字まで
・件数・金額・日付は【】にする（僕があとで実数を入れる）
次の7日分（【22】日目〜【28】日目）を、この列のCSVで出してください：
順番,区分,いつ,題,本文,続き,メモ,タグ,完了,完了した日時,画像,鍵,型
（区分＝投稿、いつ＝「22日目 07:30」の形、完了＝FALSE、鍵＝d22-0730 の形、型＝考え方／型／実録／戦略／告知）
今週のテーマ：【】
先週いちばん反応があった投稿：【題と数字】
```

出てきたCSVを `posts.csv` の下に足して `python3 ai-shigoto/tools/build_board.py` を実行するか、シートの下に貼る。

## 7. 導線（どこで、何と言って、次に進めるか）

```
Threads（毎日3本・20:30が主役）
  ├─ 固定投稿の続き ───────────▶ 無料note
  ├─ プロフのリンク1本目 ─────────▶ 無料note
  ├─ プロフのリンク2本目 ─────────▶ 公式LINE（スターターキット）
  └─ 発売週の告知の続き ─────────▶ 有料note
無料note の最後 ─────────────────▶ 公式LINE（入口_無料note）／有料note
有料note の特典の章（合言葉）───────▶ 公式LINE（入口_有料note）
公式LINE（7日間の配信）─────5日目──▶ 個別相談（30分・無料）─▶ 合う人にだけ伴走
公式LINE ─────参加コード────────▶ オープンチャット（週の部活・月1の7日間チャレンジ）
```

| 段 | 次に進める一言 |
|---|---|
| Threads → 無料note | 「順番の全体像は、無料noteにまとめています」 |
| 無料note → LINE | 「この記事を手を動かせる形にしたスターターキットを、公式LINEで配っています」 |
| 有料note → LINE | 「特典は、公式LINEに合言葉を送ると受け取れます」 |
| LINE → 個別相談 | 「自分の場合はどうすれば？と思った方へ。有料の案内もしますが、断ってもらって大丈夫です」 |

note の中身は `03_note.md`、LINEと個別相談は `04_line.md`、オープンチャットは `05_openchat.md`。

## 9. 数字（毎週日曜に10分）

| 見る数字 | どこで | 目安（仮） | 動かないときに直す所 |
|---|---|---|---|
| 1投稿あたりの閲覧 | Threads のインサイト | 2週目で1,000 | 1行目・時間・型の割合 |
| フォロワーの増え方 | Threads | 3週間で +300〜1,000 | 固定投稿・プロフ |
| プロフ → リンクを押した数 | Threads のインサイト | プロフを見た人の5〜10% | 自己紹介の最後の1行 |
| 無料note → LINE | エルメの流入経路 | 読んだ人の10〜20% | スターターキットの中身と言い方 |
| 有料noteの部数 | note | 先着30部が3日で埋まるか | 告知の順番・目次・特典 |
| LINE → 個別相談の予約 | エルメ | 友だちの5〜10% | 5日目の案内文・価格帯の伝え方 |

（仮）の数字は参考アカウントと一般的な見立て。3週間の実数が取れたら、自分の数字に置き換える。

## 10. 規約・法律

`06_rules.md` にまとめている（Threads／note／LINE・オープンチャット／特定商取引法／景品表示法）。
特に大事な3つ：
1. **実績・感想は事実だけ**。作った声、盛った数字は出さない
2. **個別相談では、最初に「有料の案内をすることがある」と言う**。伴走の申し込みは書面で、クーリングオフも説明する
3. **Addnessなど、関係のある会社のサービスを勧めるときは関係を書く**

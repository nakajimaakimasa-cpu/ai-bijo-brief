# ai-shigoto の作業ルール（ローカルの Claude Code 向け）

このフォルダは、Threads「AIで仕事を取る」アカウントの一式（設計書・投稿・note・公式LINE・オプチャ・規約）。
持ち主（あきまさ）の Mac で、ローカルの資料を読みながら仕上げる前提。

## 最初に読むもの

1. `private/LOCAL_START.md`（あれば。非公開キットに入っている。どの資料から何を拾うかが書いてある）
2. `01_account_design.md`（全体の設計。§0 の「決めてほしいこと」が未決なら、先に持ち主に聞く）
3. `06_rules.md`（守るルール）

## 置き場所のルール

- **このリポジトリは公開**。売り物（有料noteの本文・付録）、お客さんや取引先の名前、契約・お金・個人の情報は、`private/` にだけ置く（`.gitignore` 済み）
- 公開してよいのは、設計書・投稿（どうせThreadsに出る）・無料note・LINE/オプチャの設計・規約まとめ・ツール
- 迷ったら `private/` に置いて、持ち主に聞く

## 書き方のルール

- 【】は「事実に合わせて直す所」。ローカルの資料で確かめられた数字・出来事だけで埋める。確かめられなければ【】のまま残すか、数字を使わない言い方に変える
- 盛らない。作った感想・作った数字・売上のスクショで煽る、は書かない
- 使わない言葉：稼げる・不労所得・誰でも・絶対・必ず・「◯◯するだけ」（公式LINEでは特に。アカウント停止の理由になる）
- お店への連絡は「電話か訪問で、見本を送っていいかを先に聞く」。Googleマップから自動で集めない。口コミの文章や写真を見本に載せない
- 個別相談の案内には「有料の伴走を案内することがある」「事業者名・担当者名」を必ず入れる（Web会議でも電話勧誘販売の扱い）
- 実在のお店・会社・お客さんの名前は、公開する文章に出さない

## 投稿ボード

- 中身は `posts.csv`（今の「投稿ボード」シートと同じ列＋「型」）
- 直したら、リポジトリの一番上で `python3 ai-shigoto/tools/build_board.py` を実行して `board.html` を作り直す（500字超え・鍵の重複は止まって教えてくれる）
- `board.html` はブラウザで開くだけで使える（「投稿した」の記録はそのブラウザに残る）
- Google スプレッドシートで使うときは、シートで「ファイル → インポート → posts.csv」。タブ名を「ボード」にして、今のGASのボードのスクリプトを同じ形でつなぐ

## 1投稿の決まり

- 1投稿500字まで。1行目で言い切る。リンクは本文に入れず「続き」に置く
- タグは1投稿1つ（投稿画面の # から選ぶ）
- 1日3本：07:30 考え方／12:30 型／20:30 実録・戦略・告知

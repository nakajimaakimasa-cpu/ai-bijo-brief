# オープンチャット（オプチャ）の設計

**役割**：一人だと止まる人のための「部室」。毎週のリズムと、ほかの人の進み具合が見える場所。
売る場所にはしない。案内は公式LINEでする（オプチャの規約は 06_rules.md）。

```
公式LINE（7日目の配信・リッチメニュー）──参加コード──▶ オプチャ
Threads（月1回だけ「チャレンジやります」）──────────▶ 公式LINE ──▶ オプチャ
オプチャ（7日間チャレンジを終えた人）──────────────▶ 公式LINE の個別相談
```

参加は**公式LINEで参加コードを渡す形**にする（荒らしと勧誘目的の参加を減らす。誰が来ているかも追える）。

---

## 1. 基本設定

| 項目 | 内容 |
|---|---|
| 名前 | AIで最初の1件を取る部（無料） |
| 紹介文 | AIで「作れる」を「仕事」にしたい人の部室です。毎週の案件ネタ・提案文の添削会・7日間チャレンジ。売り込みなし・匿名OK。運営：あきまさ |
| 参加方法 | 参加コード（公式LINEで案内） |
| ニックネーム | 「名前｜やりたい仕事」（例：たろう｜お店のホームページ） |
| 管理 | あきまさ＋共同管理者1人（不在時の荒らし対応のため） |
| 禁止ワード | 「稼げる」「月収」「LINE交換」「DM送ります」「無料で教えます」など、勧誘でよく使われる言葉 |
| 守るガイドライン | LINE ID・ほかのSNSの連絡先・QR・電話番号・住所を投稿しない／ほかのルームの招待URLで勧誘しない／ネットワークビジネスの勧誘・送金の誘導をしない。**運営も、オプチャの中に公式LINEやnoteのURLは貼らない**（違反するとルームの削除、LINE自体の利用停止もあり得る） |

## 2. ノート（参加した人が最初に読む）

### ① はじめに読んでください

```
参加ありがとうございます、運営のあきまさです。

ここは「AIで最初の1件を取る」ための部室です。
一人だと止まりやすいので、毎週のリズムをみんなで回します。

【週の流れ】
月 20:00　今週の案件ネタ（運営から）
水 20:00　提案文の添削会（テキストで30分）
金 20:00　今週やったこと報告（1行でOK）

【最初にやること】
自己紹介を3行で書いてください。
1. 名前（ニックネームでOK）
2. やりたい仕事
3. いまの状況（まだ／応募中／実績あり）
```

### ② ルール

```
1. 売り込み・勧誘・個別のDM、LINE IDやSNSの連絡先・URLの投稿は禁止です（見つけたら退会してもらいます）
2. 実在のお店・会社の名前は出さないでください（添削に出すときは伏せる）
3. 質問は「状況／やったこと／困っていること」の3行で
4. 成果の報告は大歓迎。金額は言える範囲で
5. 運営からの案内（個別相談など）はオプチャではせず、公式LINEでします
```

## 3. 週の流れ（運営が投稿する文面）

### 月曜 20:00　今週の案件ネタ

```
【今週の案件ネタ】
今週、クラウドソーシングで多かったAIまわりの募集はこの3つでした。

1. 【案件の種類】… 取り方のコツ：【1行】
2. 【案件の種類】… 取り方のコツ：【1行】
3. 【案件の種類】… 取り方のコツ：【1行】

「自分ならどれを狙う？」を1行で返信してみてください。
```

### 水曜 20:00　提案文の添削会

```
【提案文の添削会】20:00〜20:30
添削してほしい提案文を、このトークに貼ってください。
・相手の会社名・お店の名前は伏せる
・募集文の要点も1〜2行で

30分で届いた分は全部見ます。
（見る順番：①相手の困りごとを言い直せているか ②見本があるか ③最初の確認が1つか）
```

### 金曜 20:00　今週やったこと報告

```
【今週やったこと】
1行でOKです。やったことだけ書いてください。
例）募集を10件読んで2件提案した
例）近所でサイトのないお店を5件メモした

できなかった週は「今週はゼロ」でも大丈夫。書くと来週動けます。
```

## 4. 月1回の「7日間 最初の1件チャレンジ」

告知は公式LINEとThreadsで1回ずつ。オプチャでは毎朝7時にその日の課題を出す。

| 日 | 課題 | 報告のしかた |
|---|---|---|
| 1 | やる仕事を1つに決める（「AIを使って◯◯の◯◯を作る人」） | 1行で投稿 |
| 2 | 見本を1つ作る（AIで下書き→自分で直す） | できたら「できた」だけ |
| 3 | 募集を10件読み、取れそうな3件を選ぶ | 選んだ3件の種類 |
| 4 | 3件に提案する（型どおりに） | 送った件数 |
| 5 | 近所でサイトのないお店を5件メモ | 件数 |
| 6 | 1件に「見本を見てほしい」と送る | 送った／まだ |
| 7 | 振り返り：うまくいかなかった所を1行ずつ | 3行 |

7日目の夜に公式LINEで「やり切った人向けの個別相談」を案内する（オプチャの中では案内もURLもなし。参加者はもともと公式LINEの友だちなので、LINEで届く）。

---

## 5. やらないこと

- **仕込みのコメント（サクラ）を入れない**。盛り上がって見えても、バレたときに全部の信用を失う。広告として扱われる可能性もある
- 参加者の成果を、本人の許可なく Threads や note に載せない
- 「今だけ」「あと◯名」を、事実でないのに言わない
- オプチャの中で、有料の伴走を売らない

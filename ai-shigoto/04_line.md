# 公式LINE と 個別相談（面談）の設計

**役割**：Threads と note で「この人の話は信じられる」と思った人を、**個別相談まで連れていく場所**。
LINE では売り込まない。毎晩1通、「次の一歩」だけを渡して、5日目に個別相談を案内する。

```
Threads（毎日3本）
  ├─ プロフのリンク → 無料note ─┐
  └─ 発売日の投稿 → 有料note ──┤（noteの中に合言葉）
                                 ▼
                  公式LINE（スターターキット／特典の受け取り）
                                 ▼
                  7日間の配信（毎晩20時・1通ずつ）
                                 ▼
                  個別相談（30分・オンライン・無料）
                                 ▼
                  伴走（有料）※合う人にだけ案内
```

---

## 0. 先に決めること

| 決めること | おすすめ | 理由 |
|---|---|---|
| 配信ツール | **Lメッセージ（エルメ）** | すでに別のアカウントで使っていて操作に慣れている。流入経路ごとのURL・タグ・ステップ配信・予約が1つで済む |
| LINEの料金プラン | 最初は無料 → 友だちが30人を超える前にライトへ | 7日間の配信は1人あたり7通。無料の月200通は、友だち30人弱で使い切る（料金は 06_rules.md を参照） |
| 個別相談をする人 | あきまさ本人 | Threads・noteで話している本人が出ることが、いちばんの信用になる |
| 伴走の中身と値段 | **個別相談の前に、LINEで価格帯を伝える** | 「LINE→Zoom→いきなり高額」は、それだけで詐欺を疑われる。先に伝えると、来る人が絞られて当日のキャンセルも減る |

## 1. 基本設定

- **アカウント名**：あきまさ｜AIで仕事を取る
- **プロフィール画像**：Threads と同じ顔写真
- **ステータスメッセージ**：スターターキット配布中｜AIで最初の1件
- **友だち追加のURLを入口ごとに分ける**（エルメの流入経路）

| 入口 | 付けるタグ | どこに貼るか |
|---|---|---|
| Threads のプロフ | 入口_Threads | プロフのリンク2本目 |
| 無料note | 入口_無料note | 無料noteの最後 |
| 有料note | 入口_有料note | 有料noteの特典の章（合言葉とセット） |
| オープンチャット | 入口_オプチャ | オプチャのノート（規約の範囲で） |

## 2. あいさつメッセージ（友だち追加の直後）

```
はじめまして、あきまさです。
友だち追加ありがとうございます！

約束の「スターターキット」はこちら👇
【スターターキットのURL】

・クラウドソーシングで通る提案文の型（3種）
・Googleマップで「サイトのないお店」を見つける手順
・AI社員の社則（CLAUDE.md）のひな形

先に1つだけ教えてください。
いまのあなたに一番近いのはどれですか？
```

**ボタン（回答でタグを付ける）**

| ボタン | タグ | 直後に返す内容 |
|---|---|---|
| A まだAIで仕事をしたことがない | 状況_A未経験 | 「まずは"やる仕事を1つに決める"から。キットの1ページ目をどうぞ」 |
| B 応募しているが通らない | 状況_B応募中 | 「提案文の型の②（見本つき）だけ先に読んでください。いちばん変わる所です」 |
| C 実績はあるが続く仕事にならない | 状況_C実績あり | 「納品のときの一言（毎月の仕事に変える型）を先にどうぞ」 |
| D 自分の仕事にAIを入れたい | 状況_D事業者 | 「AI社員のひな形から。社則の5行を書くだけで変わります」 |

> 有料noteの合言葉が送られてきたときは、あいさつより先に「4. note購入者の流れ」に入る。

## 3. 7日間の配信（毎晩20時・1日1通）

1通は「吹き出し3つまで・スマホで2スクロール以内」。最後は必ず「次にやること1つ」で終える。

### 1日目　AIで仕事が取れない人の「3つのずれ」

```
こんばんは、あきまさです。

AIで仕事が取れない人には、
だいたい3つの「ずれ」があります。

① やる仕事が決まっていない
　「AIで何でもできます」は、何も頼まれない

② 見せられるものがない
　提案文に「見本」がないと、読まれずに終わる

③ 取り方の順番が逆
　いきなりお店に営業して、断られ続けて折れる

今夜やることは1つだけ。
「AIを使って、◯◯の◯◯を作る人」
の◯◯を埋めてみてください。

埋まったら、このLINEに送ってください。
全部読んで、ひとこと返します。
```

### 2日目　最初の1件は「見本つき」で取る

```
きのう送ってくれた方、ありがとうございます！

今日は、最初の1件の取り方です。

クラウドソーシングで落ちる提案文は、
ほぼ全部「自分の話」から始まっています。

通る提案文は、この順番です。
1. 募集文の言葉で、相手の困りごとを言い直す
2. 近いことをやった実績（なければ見本を作る）
3. 進め方を3ステップで
4. 納期と、最初に確認したいこと1つ

いちばん効くのは「2. 見本」。
頼まれる前に作って見せると、読む側の手間が減る。

次にやること：
募集を3件読んで、そのうち1件の「見本」をAIで下書きする。
```

### 3日目　Googleマップで「サイトのないお店」を見つける

```
こんばんは、あきまさです。

クラウドソーシングで1件取れたら、
次は「近所のお店」です。

Googleマップで
「駅名＋業種」（例：◯◯駅 整体）で探して、
・口コミが多い
・でも「ウェブサイト」のボタンがない
お店をメモします。

お客さんはいるのに、
ネットで見つけてもらう入口がない状態。
提案が一番届きやすい相手です。

次にやること：
行ける範囲で5件メモする（10分でOK）。

※マップから自動で大量に集めるのは規約に触れるので、手で探してください。
```

### 4日目　作業はAI、判断と営業は人

```
今日は「AI社員」の話です。

僕はパソコンの中に「会社」のフォルダを作って、
仕事ごとにAIを置いています。

・社則（CLAUDE.md）に、仕事のやり方を書く
・AIに直したことは、社則に1行ずつ足す
・決めるのと、お客さんと話すのは自分

これで、AIに毎回ゼロから説明しなくてよくなり、
1人で複数の仕事を回せるようになりました。

AI社員の作り方・Obsidianで知識を貯める方法・
Addnessで目標とつなぐ方法は、有料noteの特典に全部書いています。
【有料noteのURL】

次にやること：
キットの「社則のひな形」の5行を埋める。
```

> **note購入者には送らない**（タグ「note購入」が付いている人は、4日目の後半の案内を外す）

### 5日目　個別相談のご案内

```
こんばんは、あきまさです。

5日間、読んでくれてありがとうございます。

ここまでで
「自分の場合はどうすればいい？」
と思った方向けに、個別相談をしています。

【内容】30分・オンライン（顔出しなしでもOK）
・あなたが「今取れる仕事」を一緒に3つ出す
・最初の30日にやることを決める

【こんな方に】
・何から手をつけるか、迷っている
・応募や営業をしているけど、手応えがない

【こんな方には向きません】
・すぐに大きく稼げる方法を探している
・作業を全部ひとに任せたい

正直にお伝えすると、
必要な方には、有料の伴走（【価格帯】）のご案内もしています。
合わなければ、その場で断ってもらって大丈夫です。
しつこい連絡はしません。

ご予約はこちら👇
【予約ページのURL】
```

### 6日目　よくある質問

```
個別相談について、よく聞かれることです。

Q. 何も準備できていなくても大丈夫？
A. 大丈夫です。事前の質問（5問）に答えてもらえれば、そこから始めます。

Q. 顔出しは必要？
A. なしでも大丈夫です。僕は顔を出します。

Q. 必ず何か買わないといけない？
A. いいえ。相談だけで終わる方も多いです。

Q. 伴走はいくら？
A. 【価格帯】です。内容と金額は、相談の中で紙（PDF）でもお渡しします。

ご予約はこちら👇
【予約ページのURL】
```

### 7日目　今月の相談枠

```
今月の個別相談は、残り【◯枠】です。

1人30分しか取れないので、
今月はここまでにしています。

迷っている方は、
「何を聞けばいいか分からない」でも大丈夫です。
事前の質問に答えてもらえれば、こちらで整理して当日を迎えます。

ご予約はこちら👇
【予約ページのURL】

来週からは、毎週水曜の夜に
「今週の案件ネタ」と「実際にやったこと」を1通ずつ送ります。
```

> 残り枠は**本当の数**だけ。作った「残りわずか」は書かない（景品表示法・信用の両方の理由）。

### 8日目以降　毎週水曜20時の1通

| 週 | 内容 |
|---|---|
| 1 | 今週見つけた「AIで取れる案件」3つと、その取り方 |
| 2 | 実録：今週出した提案と、返ってきた返事 |
| 3 | 型：そのまま使える文面1つ |
| 4 | 個別相談の案内（月1回まで） |

## 4. note購入者の流れ

1. 有料noteの特典の章に、**合言葉**（例：`設計図`）と公式LINEのURLを書く
2. 合言葉が届いたら自動で返信し、タグ「note購入」を付ける
3. 3日間だけ、購入者向けの配信に切り替える

| 日 | 内容 |
|---|---|
| 0日目（すぐ） | 特典のURL（AI社員のひな形・Obsidianの保管庫ひな形・Addness連携の手順・テンプレ集） |
| 1日目 | 「どの章から読むか」：状況A〜Dごとのおすすめの順番 |
| 3日目 | 進み具合を1問で聞く（読んだ／手を動かした／止まっている）→ 止まっている人に個別相談を案内 |

**合言葉の自動返信**

```
ご購入ありがとうございます！
特典はこちらです👇
【特典のURL】

・AI社員のひな形（CLAUDE.md と役割ごとのフォルダ）
・Obsidianの保管庫ひな形
・Addness連携の手順
・テンプレ集（提案文・お店への文面・電話の型・見積もりの型）

読んで「ここで止まった」があれば、このLINEにそのまま送ってください。
```

## 5. リッチメニュー（6マス）

| スターターキット | 取れる仕事 診断 | 無料note |
|---|---|---|
| **有料note** | **個別相談を予約** | **質問する** |

## 6. 個別相談の予約と当日まで

**予約ページ**：エルメの予約（またはGoogleカレンダーの予約枠）。1日2枠まで、30分＋前後15分あける。

**事前の質問（5問）**

1. いまのお仕事（会社員・フリーランス・自営 など）
2. 使ったことのあるAI（ChatGPT／Claude／Gemini／ほぼなし）
3. 1週間に使える時間
4. いつまでに、どうなっていたいか
5. 相談で一番聞きたいこと

**リマインド**：前日20時（URLと持ち物）、当日1時間前（URL）。来なかった人には翌日に1回だけ「別の日にしますか？」。

## 7. 個別相談（30分）の進め方

**基本の考え方**（営業の先生からもらった言葉より）
- 準備8割・アドリブ2割。台本はロープレで言えるまで練習してから使う
- 「面談」っぽさを消して、**同じ悩みを通ってきた相談相手**の位置に立つ
- 質問は1回に1つ。相手の言葉で言ってもらう
- 具体的なことを聞かれたら目的で、ふわっとしたことを聞かれたら具体で答える

| 時間 | やること | 一言目の例 |
|---|---|---|
| 0〜3分 | 名乗る・今日の流れ・**有料の案内があることを先に言う** | 「今日は"今取れる仕事を3つ出す"までやります。最後に、合う方には有料の伴走もご案内しますが、断ってもらって大丈夫です」 |
| 3〜12分 | 事前の質問をもとに聞く（今・これまで・使える時間・なりたい形） | 「事前の質問で◯◯と書いてくれていましたが、そう思ったきっかけは？」 |
| 12〜20分 | **その場でAIと一緒に「今取れる仕事」を3つ出す**（画面共有） | 「いま聞いたことをAIに渡して、取れそうな仕事を出してみますね」 |
| 20〜25分 | 最初の30日の順番を決める（どの仕事を、どこで、何件） | 「この3つだと、最初はどれが一番やれそうですか？」 |
| 25〜30分 | 一人で進めるか、伴走を使うかを選んでもらう | 「ここからは一人でも進められます。伴走が必要なら、内容と金額をお見せします」 |

**伴走を案内するとき**
- 金額・期間・中身・解約とクーリングオフを**紙（PDF）で**先に見せる
- その場で決めなくていいと伝える（「今日決めないといけない」は言わない）
- 支払いの方法と、分割の手数料は数字で見せる

**相談のあと**
- 当日中にお礼と「今日決めた30日の順番」を1枚にして送る（伴走を申し込まなかった人にも）
- 文字起こしを残し、断られた理由を1行でまとめて次に生かす（手元の分析スキルを使う）

## 8. 数字の見方（週1回）

| 段 | 見る数字 | まずの目安（仮） |
|---|---|---|
| Threads → プロフ | プロフを見た人の数 | 投稿の閲覧の1〜2% |
| プロフ → 無料note | リンクを押した数 | プロフを見た人の5〜10% |
| 無料note → LINE | 友だち追加（入口_無料note） | 読んだ人の10〜20% |
| LINE → 予約 | 予約数 | 友だちの5〜10% |
| 予約 → 相談 | 来た数 | 予約の80%以上 |
| 相談 → 伴走 | 申し込み | まずは数えるだけ |

（仮）の数字は、参考アカウントと一般的な数字からの見立て。**3週間ぶんの実数が取れたら、自分の数字に置き換える。**

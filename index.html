5章　①の設計：こう売る

投稿で信用を貯め、プロフィールで1つだけ案内し、TikTok Shop で買ってもらう

決める順番はチームメモ通り「誰に → 何を言うか → 何を売るか」。相手は「少し太めで清潔感がなく、女性経験が少ない25〜35歳の男性」（変更なし）。

1　投稿（週6本・30本まで型を変えない）

女性目線で「◯◯な男 5選」

  • 写真スライド週4本（無料で作れる）＋60秒動画週2本（1本 約350円）
  • 最後の1枚に「今日のは順番リスト #NN」
  • 全投稿に「AI生成」の表示をオン。商品を出す回は「PR」の表示と商品名をキャプションに
→
2　プロフィール

「今の1商品」＋リンク1本

  • 1行目に今売っている商品を1つだけ。「すべてAI」「PR含む」を固定
  • 個人アカウントは1,000人までリンク欄が出ない → それまでは固定コメントで商品名を伝える
  • リンクまとめページ（lit.link）の「順番リスト」1本だけ
→
3　売り場（1,000人になったら）

TikTok Shop の商品タグ

  • 18歳以上・フォロワー1,000人・本人確認で参加。報酬はお店が決める（目安 10〜15%）
  • AIキャラでの紹介は「AI生成」表示付きで可
  • それまでは A8（メンズスキンケア 初回1,000円・SPUTNICKS 15.7%）と Amazon（500人＋3件の販売で本審査）

売るもの（軸＝清潔感。3〜5品まで）

  • 眉シェーバー・鼻毛カッター・電気シェーバー・舌ブラシ・制汗剤（安い雑貨。最初の12本はPRなしで品名だけ）
  • メンズ洗顔・オールインワン（A8：初回購入 1,000円）
  • セットアップ（SPUTNICKS 15.7%）・スニーカー・香水
  • 順番：3週目から PR を6本（口臭・体臭・服・靴・香水・肌）。それぞれ7〜10日前に予告回を置く

売らないもの

  • 歯のホワイトニング・育毛剤（TikTok の規約で「報酬をもらって勧める投稿」が禁止）
  • サプリ・脱毛サロン・医療脱毛・マッチングアプリ・下着（チームの禁止案件）
  • 肌・髪・体型のビフォーアフター画像（AIで作らない）
  • 楽天ROOM は後回し（ランクを上げるのに「自分で撮った商品写真」が毎月必要）
目標：30本で再生の中央値 5,000 以上、またはフォロワー1,000人。保存÷いいね 0.2 以上。売り始めたら「クリック→購入の率」だけを見る（10%が普通）。収益の目安（あくまで推測）：1万人で月4〜22万円。最初の3か月は売上ゼロ想定。AI美女で物販が「売れた」実測はどこにも無いので、30本で数字を見て判断します。
6章　②ED・AGA を今やらない理由

TikTok では規約で不可。他人の成功例もゼロ。入金まで最短5〜6か月

TikTok　9月24日から成立しない

  • コミュニティガイドラインの改定（9/24発効）：「免許が要る医療サービス」は一般アカウントで宣伝・リンク・外部への誘導ごと禁止
  • ブランドコンテンツ規約（8/31発効）：医療機関・オンライン診療・育毛剤・ホワイトニングを「報酬をもらって勧める投稿」が禁止。リンクをプロフィールに逃がしても投稿が勧めていれば違反
  • 医療広告ガイドライン：個人の投稿でも医療広告扱い。体験談・ビフォーアフター・料金の強調が禁止
  • 薬機法：処方薬（ED治療薬）の一般向け広告は禁止＝薬の名前が出せない

もしやるなら　Instagram 限定・全部そろえてから

  • チームのルール「美容医療・サプリはやらない」を改定して記録する
  • 案件は ASP に正規掲載の「予約・来院」だけ（afb で1件 11,000〜16,922円）
  • 3人の誰かが、紹介リンクを通さずに無料カウンセリングを受ける
  • 台本に体験談・効果の断定・薬名・クリニック名・料金を入れない（機械で止める）
  • ①とは別アカウント・別キャラ。性的な要素ゼロ。DM や LINE での個別相談はしない
  • ED は AGA で承認率が読めてから

① の語り手を AI美女にしますか？

いまの台本30本は男性キャラ「リク」（一人称「俺」）で書いてあります。(a) 女性キャラに書き換える　／　(b) リクのまま　／　(c) 2アカウントで両方

提案 (c)①＝女性キャラで「女子目線」に書き換え、2つ目＝リクで同じ台本の男性版。「美女 vs 男性、どちらが売れるか」をそのまま比べられる。順番の回15本は表紙の差し替えで済むが、会話・LINE の回は本文を反転、本音の回8本は作り直し。
3

売り場の優先順位は？

TikTok Shop の商品タグ　／　lit.link の順番リスト（A8・Amazon）　／　楽天ROOM

提案TikTok Shop ＞ 順番リスト ＞ 楽天ROOM。ROOM は「自分で撮った商品写真」が要るので、実物を撮れる人がいる場合だけ。
あわせて1枚に書いておくこと：報酬が入る口座の名義人・3人の分配・TikTok Shop の本人確認を出す人・画像生成の課金を承認する人。TikTok を「個人」で作るか（曲は自由・1,000人までリンク不可）「ビジネス」で作るか（初日からリンク可・商用曲のみ）。コメントと DM の対応ルール。
8章　今週やること

決定 → ヒアリング → 台本の書き換え → キャラ生成 → アカウント作成

  1. 7章の3つを決める＋「1枚」を書く依頼主
  2. ヒアリング（変わる前・きっかけ・直した順番・言われた言葉・付き合えた時・今も使う物）→ 本音の回10本の穴を埋める依頼主 → 台本担当
  3. 台本30本を書き換えて、検査（check）を通す。最初の2週間の12本は PR なし・実話なしで出せる回を選定済み台本担当
  4. 女性キャラを生成（見積もり → 承認 → 約80円）→ 画像を書き出す制作担当
  5. TikTok・Instagram を開設（プロフィールに「すべてAI」「PR含む」）、A8（審査なし）・afb（3営業日）・もしもにアカウント登録、lit.link の順番リストを作るアカウント担当
  6. 投稿開始。1,000人で TikTok Shop に申請、500人＋販売3件で Amazon の本審査全員
9章　持ち寄りメモと実測のズレ

次から「フォロワー・直近の再生・リンクの飛び先・売り物と値段・最終投稿日」の5点を揃えて持ち寄る

  • 「TikTok内サブスク 363円」は、ログインなしの Web では確認できない。ねこなでしこの主な売り場は Patreon（有料13人）
  • 美音／mio の fanport は月額ではなく単品販売（8〜25ドル）
  • 夜勤女子の「マッチングアプリ」は出会い系サイト（短縮URLで隠している）
  • AI Moments の「ハイライト」は TikTok に無い機能。実際は動画内の Shop リンク
  • 「ショーケース」と書かれた3件（Angel Heart・ai_atsushi・さくらこ）は3件とも無し
  • あいすの「AV・写真集」、まな・みおの「myfans」は、どこにもリンクが無い
  • カズの lit.link に FANZA のリンクは無い（X のアカウント5本）
  • さりナは AI ではなく実在タレント。プロフィールのリンクは 404
  • Rクリニックの例の動画は削除済み。X の love_ky_ss は「AI美女で稼ぐ方法」を売る側
調べ方：TikTok のプロフィール（埋め込みデータ）、直近100本の再生数（yt-dlp）、プロフィールのリンクが最終的にどこへ飛ぶか（curl）。AI に「23件の分解 → 案件と規約の調査 → 3つの視点で審査 → 主張12件を反証 → 追加調査」をさせ、反証で崩れた言い方は直してあります。
